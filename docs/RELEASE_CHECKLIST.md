# Before publishing publicly

- [ ] Confirm ownership of all original notebook/code, saved model, and screenshot.
- [ ] Confirm permission to publish the model trained on the source MRI data.
- [ ] Review participant/patient image privacy and data licenses; raw scans are not included.
- [ ] Remove patient or team identifiers from any new screenshots, paths, Git history, and logs.
- [ ] Choose a software license only after confirming your rights. No license is granted by default.
- [ ] Run on your own data; record environment versions, train/val/test split, and Dice/IoU.
- [ ] Use a verified patient-level split if patient IDs are available.
- [ ] Check GitHub Actions and verify that the local demo works.

This is an educational computer-vision demonstration; **not a medical device**.
